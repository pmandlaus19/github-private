Overview

This topic describes process integration, yield control, and line qualification. It is generated for large-scale authoring, indexing, post-processing, search, and publishing validation.

Procedure

  1. Verify the process recipe and approved operating window.
  2. Load the wafer lot and validate equipment readiness.
  3. Execute the configured process and capture metrology results.
  4. Compare the measured values against specification limits.
  5. Record deviations and initiate corrective action where required.
