Installing the Software

Follow these steps to install the sample application.
PREREQUISITE Before you begin, confirm that your system meets the minimum requirements.
Administrator privileges are required to complete this installation on managed devices.
  1. Download the installer package from the distribution portal.
  2. Run the installer with administrator privileges.
    ADDITIONAL INFORMATION: This step is only required for administrator-managed installations and is filtered out of the end-user edition of this guide.
  3. Accept the Windows firewall prompt to allow network access.
  4. Complete the setup wizard and confirm the installation succeeded.
    STEP RESULT:
ResultThe application is installed and ready to use.
AFTER COMPLETING THE TASKContinue to API Parameters to configure the application.
